# Market & Portfolio Lab

真实数据驱动的系统化投资研究与决策项目：从基础逐步建立收益信号、风险预测、组合构建、执行模拟与持续复盘。图表和 Notebook 服务于理解与验证，最终目标是帮助使用者判断当前持仓风险、是否值得调整，以及调整的依据和成本。

## 项目定位与开发原则

2026-10-08 确定的方向：慢慢学习，把每一步做扎实，同时为机器学习、AI 和更复杂策略保留扩展空间。当前完成环境、数据快照、基础分析、教学账本和首个动态风险配置实验；更高级模块仍为开发路线。

- 先完成小而可信的投资决策流程，再增加模型复杂度。不以功能数量或历史最高收益作为进度指标。
- 初期研究 SPY、IEF、GLD，日频数据、月度调仓、只做多且不加杠杆。先模拟账户；真实持仓分析可后续接入，实盘下单是独立阶段。
- 每个新方法都与简单基准比较，分别评价预测、风险、成本与组合结果。风险降低不自动等于创造 alpha。
- Notebook 用于教学和实验；经过验证、需要重复运行的逻辑放入 `src/`。参数、数据快照、模型版本和运行结果需要可追溯。
- 暂不搭建空框架或安装高级模型依赖；实现当前模块时定义必要接口，让后续方法可替换、可比较。

## 模块边界与未来扩展

以下是逐步落实的接口约定，而非已存在的 API。

| 模块 | 输入与输出 | 未来扩展位置 |
| --- | --- | --- |
| 数据 | 带来源、时间、质量标记的行情/事件 → 可复现数据快照 | 财报、宏观、新闻、其他数据供应商 |
| 特征与收益信号 | 决策时已可获得的数据 → 带资产、决策时间、预测期限的分数或收益预测 | 趋势、动量、线性模型、树模型、深度学习 |
| 风险 | 历史信息 → 对应资产和期限的波动率、协方差等估计 | EWMA、收缩估计、状态模型、机器学习 |
| 组合决策 | 信号、风险、现有持仓、现金、成本及约束 → 目标权重与调整理由 | 风险平价、优化配置、多策略资金分配 |
| 执行与账本 | 目标和当前持仓 → 订单建议、模拟成交、股数及现金记录 | 券商模拟接口、执行成本研究；实盘另行接入 |
| 评价与监控 | 预测、决策、成交及后续真实结果 → 基准对比、归因和异常记录 | 模型漂移、策略失效分析、运行告警 |

所有预测输出都必须明确：什么时候产生、当时使用什么信息、预测哪个资产和多长时间。分数与预期收益不能混用；模型无有效预测时必须显式标记。组合和执行模块独立检查现金、仓位、数据时效和交易约束，不能由预测模型跳过。

AI 可以先辅助整理研究、解释报告；以后若用于提取新闻信号或预测，必须像其他模型一样接受时间对齐、样本外和成本检验，记录来源与版本。更复杂策略在适用范围内复用公共模块；期货、期权、做空或高频策略还需增加相应数据、账本与成交机制，不能仅替换一个模型就宣称已支持。

## 按验收结果推进的路线

1. **数据与基础理解（已完成首版）**：快照、校验、收益与风险指标；后续补充交易日历与交叉来源核查。
2. **可核对的基准组合（已完成教学首版）**：固定 60/40 股债和三资产等权；记录权重漂移、调仓、费用、股数与现金。明确分红、成交时点及零碎股假设，资产总值可由账本重建。真实分红到账和订单成交机制仍需进一步完善。
3. **风险配置（已完成首个对照实验）**：126 日反波动率目标、风险贡献分解、与固定配置同区间比较。后续再研究风险平价、配置约束、风险估计与调仓容忍区间。
4. **收益信号研究**：加入趋势/动量，对比固定配置、风险配置、风险配置加信号；隔离每项改动的作用，再考虑机器学习。
5. **投资决策报告与持续模拟**：输入持仓、现金及用户设定约束，输出风险、目标与现有权重、拟交易数量、成本假设、理由和数据时间。支持“不交易”与数据异常暂停，保存每日记录并对账。
6. **高级研究与接入**：基于已验证流程引入更多资产、模型和模拟交易接口。用运行稳定性与前瞻记录评价成熟度；短期模拟盈利不能证明长期优势。

历史研究采用按时间推进的验证，训练和参数选择只使用相应时点之前的信息。已经看过的历史区间不称为完全未接触的测试集；冻结规则后持续记录新数据上的表现。研究用调整后价格计算收益，执行账本使用实际价格、股数、现金及分红事件，避免重复计入分红。收盘后产生的信号不能假设已按该收盘价成交。

## 环境

- 项目内 Conda 环境：`.venv`，Python 3.11。
- `requirements.txt`：直接依赖及兼容范围。
- `requirements-lock.txt`：安装验证后记录的精确 Python 包版本。
- `environment.yml`：用于重建环境的配置。

本环境沿用现有 Anaconda 的 Intel/x86_64 架构，使用预编译依赖包；锁定版本主要用于本机重建，换到其他架构时需要重新验证。

工具包括 pandas、NumPy、SciPy、Matplotlib、Plotly、PyArrow、yfinance、scikit-learn、skfolio、JupyterLab 和 ipykernel。

| 60/40 月度调仓 | 9.75% | 9.74% | -21.20% |

首次决策（2010-07-30）估计的 60/40 风险占比：SPY 113.92%、IEF -13.92%，负贡献代表估计下的波动抵消作用。首次反波动率资金占比约 19.03% / 58.70% / 22.27%，风险占比约 20.98% / 19.03% / 59.99%，说明反波动率不等于一般情形下的风险平价。

本段历史中，反波动率降低整体波动，但没有改善相对等权的最大回撤，收益也较低。这不证明方法在所有时期无效，也不能推导出 alpha。三种组合未匹配到同一风险水平，尚未评价风险预测的前瞻准确性。仍沿用第二课的分红现金和理想化执行简化；没有实盘订单、收益预测、仓位上限或杠杆。
